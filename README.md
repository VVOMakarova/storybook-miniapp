# storybook-miniapp

Telegram Mini App — форма заказа сказки для продукта **Story Reef** («Сказки Пузырька»).
Весь код — один файл `index.html` (разметка, стили, логика, двуязычие RU/EN).

Форма собирает параметры книги и отправляет их в воркфлоу генерации n8n
(`https://oglob.app.n8n.cloud`), запущенный на инстансе заказчика.

## Отношение к репозиторию `story-reef`

Это **отдельный** репозиторий и отдельная поверхность.

| | `story-reef` | этот репозиторий |
| --- | --- | --- |
| Что | Сайт + три Node-сервиса + движок n8n | Одна HTML-страница |
| Где живёт | `story-reef-stage.arba.agency`, хост stage | Telegram Mini App |
| Форма заказа | `site/order.html` — веб-нативная, без Telegram | эта |

⚠️ **Продукт переведён на веб-нативный флоу, Telegram из процесса убран.** Основная форма
заказа — `site/order.html` в репозитории `story-reef`. Эта страница осталась от
Telegram-версии: она ходит напрямую в n8n, минуя `orders-service`, а значит **не создаёт
заказ в Postgres, не проходит оплату Stripe и не участвует в двухшаговом флоу**
(превью персонажей → согласование → оплата → полная генерация).

Прежде чем что-то здесь править, убедитесь, что задача действительно про Telegram-поверхность,
а не про основной продукт. Последнее изменение — 2026-06-01.

## Деплой

Ansible-роли и записи в инвентаре AR-Infra у этого репозитория нет: страница публикуется
как Mini App средствами Telegram, а не разворачивается на наши хосты.
